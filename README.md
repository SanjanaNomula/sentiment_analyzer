# Sentiment Analysis Project

This project is an advanced sentiment analysis application that utilizes Natural Language Processing (NLP) techniques to predict the sentiment (positive or negative) of a given text input. Built using Python, the application leverages the power of the NLTK library for text processing and analysis. The model is trained using the Bag of Words algorithm to classify the sentiment. The application is deployed with Streamlit, providing an intuitive and user-friendly interface.

You can interact with the deployed application directly by visiting [this link](https://sentimentanalyzer-fs6to3ayc79wuf3khzykjx.streamlit.app/).

## Key Features

- **Sentiment Prediction**: The application predicts whether the input text is positive or negative based on its content.
- **User-Friendly Interface**: Built with Streamlit, the app offers an easy and engaging user experience for interacting with the sentiment analysis tool.
- **Online Deployment**: Accessible via a web browser, making it easy to use without any installation on the local machine.
- **Real-Time Analysis**: Analyze the sentiment of any text input in real time by simply clicking the "Analyze" button.

## Usage Instructions

1. **Launch the Application**:
   - go to the [application link](https://sentimentanalyzer-fs6to3ayc79wuf3khzykjx.streamlit.app/).
   
2. **Input Text**:
   - In the provided text box, enter the text whose sentiment you wish to analyze.
   
3. **Analyze Sentiment**:
   - After entering the text, Press Enter button to get the sentiment prediction (positive or negative).

4. **View the Result**:
   - The application will display the predicted sentiment based on the input text.

## Dependencies

- Python 3.6 or higher
- Streamlit (for deploying the web application)
- NLTK (Natural Language Toolkit for text processing)
- Pandas (for handling data)
  
Make sure to install all the required packages by using the command below:
```bash
pip install -r requirements.txt
```
